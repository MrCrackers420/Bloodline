# Bloodline

A war fought in blood, across two rivers. A single-file browser card battler.

The Pages site opens **Latch 98**, a Windows-98-style desktop with Bloodline and other programs inside.

- Latch 98: `https://<your-github-name>.github.io/<this-repo>/`
- Bloodline on its own: `https://<your-github-name>.github.io/<this-repo>/bloodline/` (install it to your home screen for full screen, offline play)
- Latch 98 for Android: the APK on the `latch98-android` Release.

For developers (and Claude Code): see `CLAUDE.md`.
