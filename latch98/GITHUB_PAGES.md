# GitHub Pages: Latch 98 as the main website

Deploy this folder to the `latch98/` directory in `MrCrackers420/Bloodline`.

Replace `.github/workflows/pages.yml` with `latch98/tools/BLOODLINE_pages.yml.example`.
The workflow publishes Latch 98 at site root, mirrors it under `/latch98/`,
and copies the *existing* `game/bloodline.html` without modifying it.

**GitHub Pages URLs after a successful deployment:**
- `/Bloodline/`: Latch 98 (default)
- `/Bloodline/game/bloodline.html`: Original Bloodline, no Latch UI
- `/Bloodline/bloodline/`: installable Bloodline site generated by the existing build tool
- `/Bloodline/latch98/`: optional legacy Latch address
- `/Bloodline/apps/norn-world-lab/index.html`: Step 32 standalone Norn

The normal desktop shortcut navigates to `/game/bloodline.html`, entirely
leaving the desktop; the Windowed shortcut embeds that same file in the
Latch desktop. The Norn lab is installed in-world via Postbox, SwarmWire,
D:\ Setup, and the game iframe has shared access to LatchFS.

For the **Rust** host, copy the unchanged Bloodline source into
`Latch98/game/bloodline.html` before `cargo run --release` to make
`/game/bloodline.html` available. The Rust host is not used on GitHub Pages.

To test locally: `python -m http.server 8000 -d site` and open the root.
The source code and tests remain in `latch98/`, not in the generated Pages root.
