# Norn World Lab — Round 7 approved app-only release

The current `index.html` is the unchanged **Round 7 trained** standalone Norn
World Lab imported from `NornWorldLab-Round7-Latch-App.zip`.

* This game is not available by default in Latch 98. Install it through
  Postbox → SwarmWire → NornWorldLab.iso → mount D: → Setup.exe.
* Once installed, launch from Start → Programs → Games → Norn World Lab.
* Egg Maker includes optional 5- and 15-minute learned motor profiles; the
  ordinary default choices remain unchanged.
* The Norn game is self-contained and is embedded in a Latch window; do not
  add a second taskbar or customize its simulation from the Latch project.
* Hash/provenance: see `coordination/norn_snapshot.json` and
  `NORN_WORLD_LAB_HANDOFF.md`.

The ISO and torrent are in-world simulated virtual files, not actual ISO
or BitTorrent downloads. Offline standalone Latch packs the application for
loading *after* its normal in-world installation procedure.
