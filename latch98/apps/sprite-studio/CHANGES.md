# Latch 98 Round 3 — Thread 5 Sprite Studio changes

**Owner:** `sprite` — all changes inside `apps/sprite-studio/**` only. Based on frozen `LATCH-R3-2026-11-01` archive. No desktop, LatchFS, Norn World Lab, games, build-system, or other-owner changes.

## Functional improvements

- Added selection rectangle, cell-accurate drag movement, internal cross-frame cut/copy/paste, horizontal/vertical flip, select all/deselect. Interactions use deterministic model operations and respect stored exact unpremultiplied RGBA (including alpha-zero RGB). Each changed operation is undoable; a selection drag is one history transaction and cancelling a multi-touch gesture restores original pixels.
- Added one-pixel layer-cel movement controls, optionally across **all frames** as one undoable operation. Existing layer ordering, frame timing, onion skin and history remain intact.
- Added 100%, 150%, 250% and 500% zooms. Grid/checkerboard/drawn pixels/selection share the same CSS cell origin. Tested device pixel ratios 1, 1.25 and 2.5, scroll pan, canvas resize, painting cells at fractional zoom, and touch behavior.
- Added real PNG + manifest sprite-sheet import with strict validation, sorting by original index, exact RGBA frame pixels and original millisecond durations. The saved native v1 project format remains unchanged. Imported sprite sheets flatten layers and cannot reconstruct custom palette/layer organization; native JSON is still the full-fidelity path.
- Expanded lossless PNG decoder's bound checks with a guarded separate sheet-size mode so sheets wider than 256px can be opened; ordinary PNG import retains original 256px dimension limit. No external network/library dependencies.
- Examined Flipnote requirement without inventing compatibility: the referenced toolkit and genuine fixture archive were not supplied; no Nintendo signing keys, samples or Flipnote code added; no `.ppm`/`.kwz` support claimed. See `FLIPNOTE_REVIEW.md`.
- Rebuilt the same self-contained offline `index.html` from owned source files; Latch's existing launcher continues opening it without changes.

## Regression and fixtures

- Extended model tests (15 cases) including source selection/move/flip, undo and layer movement across frames, and a `.lss.json` fixture generated by the **unchanged Round 3 baseline**.
- Added `tests/fixtures/three-frame-sheet.json` with deliberately shuffled entries and its **real byte-valid PNG fixture encoded as UTF-8 `.png.base64`**, plus sheet roundtrip/malformed-input tests. No proprietary samples and no binary patch members.
- Added browser workflow tests for selection drag, undo/redo, cut/paste, all-frame layer movement, sheet import and export/reimport, independent onion-skin display, fractional zoom and high-DPI interaction.

## Limitations

- Rectangular selection only, not arbitrary lasso or 90° rotate. Pixel drags and layer nudges can crop off-canvas pixels; Undo restores them.
- PNG+manifest is composite-only import. Its palette is reconstructed with Sprite Studio defaults, not the original custom project palette.
- Flipnote Studio PPM/KWZ not imported/exported; no audio engine or signing support. Real fixtures/toolkit must be provided and separately licensed/reviewed.
- Browser tests use Chromium/Playwright and Pillow; runtime needs only the self-contained HTML.
