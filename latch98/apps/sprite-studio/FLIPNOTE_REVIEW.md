# Flipnote interoperability: honest Round 3 status

**Status: not implemented; no `.ppm` or `.kwz` import/export offered.**

The Thread 5 instructions refer to a user-supplied `Flipnote-Toolkit-JS-main.zip`, but that archive is **not present** among the three files supplied to this worker, nor anywhere inside the frozen Round 3 baseline ZIP. The native PPM and KWZ fixture files required for independent format-accurate tests are also absent. We did not substitute a fake container, rename PNGs, silently adopt a similarly named project, or claim compatibility without fixtures.

### Format and fidelity considerations

- Nintendo Flipnote Studio **`.ppm` is not Netpbm PPM**; Flipnote Studio 3D `.kwz` is a different proprietary animation format. Both require specialized parsing/decoding (inter-frame dependencies, palettes and metadata), not simply PNG decode. The two systems have separate animation/frame and audio specifications.
- A future importer should first verify actual magic/headers, limits, frame decoding, order and frame-rate mapping against genuinely produced PPM and KWZ fixtures. Converting their fixed palettes into Sprite Studio RGBA can preserve displayed colors but not necessarily proprietary indexed pen/layer modes, original frame encodings, edit flags, metadata or digital signatures. Sprite Studio has no sound tracks, so Flipnote audio must be explicitly reported as **not imported**.
- PNG + Sprite Studio's JSON manifest is an **independently documented Sprite Studio format**, not a Flipnote export.

### License and signing/security boundary

- There are no third-party runtime libraries or external assets in this release. All Sprite Studio source and test fixtures are original to this patch or generated by the provided editor code; it works fully offline.
- The instructions indicate the referenced Flipnote Toolkit JS is dedicated to the public domain under the Unlicense. That dedication **cannot grant rights over Nintendo proprietary signing keys or assets** that might appear in third-party archives. Any future vendor review must inspect every key/sample and remove materials lacking a clear redistribution grant.
- A publicly documented independent option is [jaames/flipnote.js](https://github.com/jaames/flipnote.js/), which currently describes MIT-licensed read-only parsing of PPM and KWZ. It is **a different project** and has not been vendored. License notices and fixture licenses require a separate review before use.

### Proposed validation before enabling a future importer

Obtain the exact supplied toolkit source archive and at least one explicitly licensed genuine `.ppm` and `.kwz` sample with known frame count, dimensions, timing and palette behavior. Parse them without network access or proprietary signing keys; test all frames and composite RGBA against an independent reference; reject truncated/corrupted data; log any palette, animation-rate, layer and audio losses. Export must remain disabled without fully tested format writers. Do not replace or rebuild other applications as part of this work.
